# Local E2E Blockchain PR Gate — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a hermetic, fully-local blockchain E2E job that runs the wallet's core Chrome specs against a locally-orchestrated Miden stack (node + prover + note-transport) on every PR.

**Architecture:** Two shippable PRs. **PR A** fixes the `localhost`→`localnet` build-enum bug that breaks the localhost extension build today. **PR B** adds a `docker compose`-orchestrated Linux stack (node topology + remote-prover from `ghcr.io/0xmiden/*:v0.15.0`, note-transport built from source) and a `pr-e2e-local.yml` workflow that builds the extension for localnet, brings the stack up, and runs the 7 core specs. The Chrome playwright harness is **already wired** for the `localhost` environment (`playwright/e2e/config/environments.ts`) — no harness code changes are needed.

**Tech Stack:** TypeScript/Vite (extension build), Jest (unit test), Playwright (E2E), Docker Compose, GitHub Actions, `miden-client-cli` (Rust, cargo-installed), `ghcr.io/0xmiden/miden-*` images.

## Global Constraints

- **Platform:** Chrome-only, `ubuntu-latest`. Mobile stays on the existing `e2e-blockchain.yml` main-only run. (spec D1)
- **Spec set (verbatim):** `wallet-lifecycle`, `mint-and-balance`, `send-public`, `send-public-local-prove`, `multi-account`, `multi-claim`, `send-private`. (spec D2)
- **Version pinning:** exact tags only, never floating. Node/prover images at an exact `v0.15.0` tag; `miden-client-cli` at the rev already pinned in `package.json` (`midenClientCliGit.rev` or `midenClientCliVersion`); note-transport at an exact git ref. (spec §7, blocker 3)
- **Token convention:** the wallet build enum uses `localnet` (`MIDEN_NETWORK_NAME.LOCALNET = 'localnet'`); the E2E harness/CLI token stays `localhost` (`E2E_NETWORK=localhost`, `networkFlag: 'localhost'`). The wallet normalizes `localhost`→`LOCALNET` at build time (PR A). Do **not** rename the harness token.
- **Code style (CLAUDE.md):** no `any`, no `as` for new code; Prettier 120-col single-quote. Commit messages single-line, short, never signed. Never `git push` without explicit request.
- **CHANGELOG:** one-liner per PR under a `## <next-version> (TBD)` heading; verify the heading's version is strictly newer than `gh api repos/0xMiden/wallet/releases/latest`.

```typescript
/**
 * Resolve a raw MIDEN_NETWORK build token to a wallet network enum.
 * The E2E harness builds the localnet bundle with MIDEN_NETWORK=localhost
 * (its network token), but the wallet enum key is 'localnet' — normalize it
 * so the localhost E2E build resolves endpoints instead of throwing.
 */
export function resolveNetworkName(raw: string | undefined): MIDEN_NETWORK_NAME {
  if (raw === 'localhost') return MIDEN_NETWORK_NAME.LOCALNET;
  const values = Object.values(MIDEN_NETWORK_NAME) as string[];
  return values.includes(raw ?? '') ? (raw as MIDEN_NETWORK_NAME) : MIDEN_NETWORK_NAME.TESTNET;
}

export const DEFAULT_NETWORK = resolveNetworkName(process.env.MIDEN_NETWORK);
```

### Task 4: Note-transport host binary

**Files:**
- Create: `playwright/e2e/local-stack/run-note-transport.sh`

**Interfaces:**
- Produces: a background `miden-note-transport-node-bin` on `127.0.0.1:57292` (in-memory sqlite), matching `environments.ts` `localhost.transportUrl`.

- [ ] **Step 1: Write the run script**

Create `playwright/e2e/local-stack/run-note-transport.sh`:

```bash
#!/usr/bin/env bash
# Build (cached) + run the note-transport service on 127.0.0.1:57292.
# Reads NOTE_TRANSPORT_REPO / NOTE_TRANSPORT_REF from versions.env.
set -euo pipefail
here="$(cd "$(dirname "$0")" && pwd)"
# shellcheck disable=SC1091
source "$here/versions.env"
work="${RUNNER_TEMP:-/tmp}/note-transport"
if [ ! -x "$work/target/release/miden-note-transport-node-bin" ]; then
  rm -rf "$work"; git clone --depth 1 --branch "$NOTE_TRANSPORT_REF" "$NOTE_TRANSPORT_REPO" "$work"
  ( cd "$work" && cargo build --release --locked --bin miden-note-transport-node-bin )
fi
"$work/target/release/miden-note-transport-node-bin" &
echo $! > "${RUNNER_TEMP:-/tmp}/note-transport.pid"
# Wait for the port (defaults 127.0.0.1:57292, :memory: sqlite — no flags)
for _ in $(seq 1 60); do nc -z 127.0.0.1 57292 && exit 0; sleep 1; done
echo "note-transport did not open :57292" >&2; exit 1
```

### Task 5: The `pr-e2e-local.yml` workflow

**Files:**
- Create: `.github/workflows/pr-e2e-local.yml`

**Interfaces:**
- Consumes: `docker-compose.local.yml`, `run-note-transport.sh`, `versions.env`, the PR-A localnet build.
- Produces: a `pull_request` check `local-e2e (chrome)` that is green iff the 7 core specs pass against the local stack.

- [ ] **Step 1: Write the workflow**

Create `.github/workflows/pr-e2e-local.yml`:

```yaml
name: Local E2E (Chrome)
on:
  pull_request:
concurrency:
  group: local-e2e-${{ github.ref }}
  cancel-in-progress: true
permissions:
  contents: read
jobs:
  chrome-local:
    name: local-e2e (chrome)
    runs-on: ubuntu-latest
    timeout-minutes: 25
    env:
      E2E_NETWORK: localhost
      MIDEN_NTX_AUTH: e2e-ntx-secret
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 22, cache: yarn }
      - uses: dtolnay/rust-toolchain@stable
      - name: Cache cargo (cli + note-transport)
        uses: actions/cache@v4
        with:
          path: |
            ~/.cargo/bin
            ~/.cargo/registry
            ${{ runner.temp }}/note-transport/target
          key: local-e2e-cargo-${{ hashFiles('package.json', 'playwright/e2e/local-stack/versions.env') }}
      - run: yarn install --frozen-lockfile
      - name: Bring up node + prover
        working-directory: playwright/e2e/local-stack
        run: docker compose --env-file versions.env -f docker-compose.local.yml up --wait --timeout 300
      - name: Start note-transport
        run: playwright/e2e/local-stack/run-note-transport.sh
      - name: Build extension (localnet)
        run: E2E_NETWORK=localhost yarn test:e2e:blockchain:build
      - name: Install Playwright browser
        run: npx playwright install --with-deps chromium
      - name: Run core specs
        run: E2E_NETWORK=localhost yarn test:e2e:blockchain:run
      - name: Dump stack logs on failure
        if: failure()
        working-directory: playwright/e2e/local-stack
        run: docker compose -f docker-compose.local.yml logs --no-color | tail -400
      - uses: actions/upload-artifact@v4
        if: failure()
        with:
          name: local-e2e-report
          path: test-results/
      - name: Tear down
        if: always()
        working-directory: playwright/e2e/local-stack
        run: docker compose -f docker-compose.local.yml down -v || true
```

Note: `test:e2e:blockchain:run` runs the full `playwright/e2e/tests/` dir; the 7 core specs are exactly its Chrome contents. If the dir gains non-core specs later, pin the list with `--grep`.
