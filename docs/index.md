# Miden Wallet

The official non-custodial wallet for the [Miden](https://miden.fi) blockchain.

- **Source code:** [github.com/0xMiden/wallet](https://github.com/0xMiden/wallet)
- **Privacy policy:** [/privacy/](./privacy/)
- **Issues / support:** [github.com/0xMiden/wallet/issues](https://github.com/0xMiden/wallet/issues)

## Download

- **Android:** Google Play Store (coming soon)
- **iOS:** Apple App Store (coming soon)
- **Browser extension:** [Releases](https://github.com/0xMiden/wallet/releases)
- **Desktop (Tauri):** [Releases](https://github.com/0xMiden/wallet/releases)

## What it does

Miden Wallet lets you create accounts, send and receive assets, and run transactions on the Miden blockchain — fully non-custodial, with private keys generated and stored encrypted on your device. Biometric unlock (Face ID / Fingerprint) is supported on mobile.
