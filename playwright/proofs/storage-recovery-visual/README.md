# Recovery visual fixture

This CI-only fixture renders production recovery page, file flow, controls and CSS with synthetic local responses. Authentication is a fixture button and no real wallet, secret, network operation or native share sheet is used. Screenshots cover three viewport sizes and both themes, including keyboard focus, export, import, loading and error states. Each screenshot is immediately capped at 1800 pixels and its dimensions are checked.

The resulting browser evidence does not prove native iOS or Android interactions, safe-area behavior, platform file sharing or real protector authentication. Those remain separate gates.
