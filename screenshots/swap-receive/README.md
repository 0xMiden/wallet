# Receive-driven swap preview

Actual iOS simulator screenshots, captured on iPhone 17 Pro, iOS 26.5.
Amounts, token registry and solver responses are synthetic fixtures used only for UI review.
The mock SDK account is unfunded; transaction submission is disabled in the local preview.
The fixture and submission-blocking script are not shipped in the application.

Typing 100 USDCX preserves that receive target and calculates a fee/slippage-aware
payment of 0.040060070075077579 ETH for this synthetic quote. The compact display
is approximately 0.04006007 ETH; review details retain the exact payment.
